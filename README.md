# Personal Website & Travel Blog

A responsive personal website featuring a personal introduction, travel stories, photography, and contact information. The project is built with HTML, CSS, JavaScript, and Bootstrap-based frontend assets.

## Website Preview

![Personal Website hero image](images/UPJ_1.jpg)

> The image above is an original visual asset already used as the website's home-page background. It is not a full-page browser screenshot.

## Pages

- **Home** — personal introduction and landing page.
- **Travel** — travel-related content and stories.
- **About** — personal profile and background.
- **Photography** — photography gallery and visual content.
- **Single** — individual article/detail page.
- **Contact** — general location and a link to the GitHub profile; the page does not collect form submissions.

## Built With

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery and frontend plugins
- Google Fonts (Poppins and Montserrat)

## Run Locally

No backend or package installation is required for the static website.

1. Clone this repository:

   ```bash
   git clone https://github.com/Arayandra/personal-website-travel-blog.git
   cd personal-website-travel-blog
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

For a more reliable local preview, you can use the VS Code **Live Server** extension.

## Notes

- Keep the `css/`, `js/`, `fonts/`, and `images/` directories in their original locations because the HTML pages reference these relative paths.
- This is a static frontend project; no database or server-side setup is required to preview the pages.
